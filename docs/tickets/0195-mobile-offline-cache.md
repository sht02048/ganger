# 0195 모바일 마지막 Dashboard·런 상세 디스크 캐시

## 배경

Orca 모바일 구조 비교(2026-11-23) 결과 운영자가 고른 개선이다. 지금 앱은 마지막 내용을 메모리에만 두어, 앱을 다시 켜면 서버에 닿기 전까지 아무것도 보이지 않는다. 같은 앱 연결·세션 파일을 고치므로 0194 뒤에 한다.

## 운영자 결정 (2026-11-23)

- 서버·Workspace마다 마지막 Dashboard와 최근 연 런 상세 20개를 캐시한다. Runners와 설정은 캐시하지 않는다.
- 앱 전용 파일에 두고 추가 암호화 없이 iOS 데이터 보호(첫 잠금 해제 뒤 읽음)를 쓴다. 연결을 끊거나 토큰이 거절되면 그 서버의 캐시를 바로 지운다.
- 캐시 형식 버전이 다르거나 저장한 지 7일이 지나면 버린다. 7일 안이면 "n분 전 기준" 띠와 함께 보인다.
- 앱을 켜면 캐시를 바로 보이고 동시에 새로 읽는다. 새 내용이 오면 바꿔 끼우고, 그 사이에는 띠를 보이지 않는다. 닿지 않으면 띠를 보이고 행동 버튼을 끈다(M31).
- 알림으로 열었는데 캐시에 그 런이 있으면 런 상세를 캐시로 먼저 보인다.

## 완료 조건

- [ ] 서버·Workspace별 Dashboard와 최근 런 상세 20개를 저장하고 읽는다.
- [ ] 연결 끊기·토큰 거절 때 그 서버의 캐시를 지운다.
- [ ] 형식 버전이 다르거나 7일이 지난 캐시를 버린다.
- [ ] 켤 때 캐시를 먼저 보이고 새 내용으로 바꿔 끼우며, 닿지 않으면 띠와 행동 버튼 끄기를 보인다.
- [ ] 알림으로 연 런을 캐시로 먼저 보인다.
- [ ] 스펙 0002에 M56으로 적는다.
