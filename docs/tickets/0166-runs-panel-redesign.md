# 0166 Runs 상세 패널 다시 짜기

## 목표

Runs 목록 오른쪽 패널은 같은 내용을 여러 번 보인다. 머리의 상태 알약에 더해 정의 목록에 "상태", "요약 결과" 알약, "PR 상태", "PR" 줄이 또 있다. 반면 0150에서 더한 PR의 CI·충돌·뒤처짐은 패널에 없다. "자세히 보기"와 "PR 열기"도 같은 모양의 글 링크다. 운영자가 시안(After 두 보드)을 골랐다(2026-11-21).

## 결정 (시안대로)

- **머리.** 첫 줄은 티켓 번호 · 트래커 프로젝트 · 브랜치(고정폭)다. 둘째 줄은 제목(티켓 제목이 없으면 번호), 셋째 줄은 상태 알약과 시간이다. 끝난 런은 "N ago 끝남 · M 걸림", 진행 중은 경과, Queued는 기다린 시간, Paused는 멈춘 시간이다. 그 아래 이유 문장을 둔다(지금 문장 그대로). 취소 중 표시도 지금처럼 둔다.
- **이유 문장.** 끝난 런의 PR이 Open이고 CI가 실패했으면 이유 문장 끝에 "PR의 CI가 실패해서 확인이 필요해요."를 붙인다. 런 결과는 바꾸지 않는다(스펙 0005 R1).
- **행동.** "자세히 보기"는 주 버튼이다(지금 링크 동작 그대로: 일반 클릭은 화면 안 이동, 수정키 클릭은 새 탭). PR이 있으면 "PR #N ↗" 보조 버튼(새 탭)을 둔다.
- **PR 구역.** 구역 이름은 "PR #N"이고 옆에 PR 상태(Open·Merged·Closed), 오른쪽에 읽은 때를 둔다. 안에는 줄마다 이름, 아이콘, 값을 둔다. CI(통과·N개 중 M개 실패·도는 중·없음, 실패면 실패한 검사 링크), 충돌(없음·있음·모름), base(N커밋 뒤·최신)다. 아이콘은 통과·문제·경고가 모양으로도 다르다. PR이 없으면 "아직 PR이 없어요", PR을 못 읽었으면 지금 못 읽음 문장을 둔다. 값은 0150의 PR 신호 데이터를 그대로 쓴다.
- **런 정보.** 러너(Offline이면 알약), 에이전트, 에이전트 결과(끝난 런만)만 둔다. "상태", "요약 결과", "PR 상태", "PR" 줄은 없앤다.
- **간격·모양.** 구역 사이는 구역 안 간격의 두 배 이상이다. 둥글기는 카드 12px, 행·버튼 8px, 알약 6px(ADR 0010)다. 필요한 모양이 `packages/ui`에 없으면 거기에 더한다. 0164·0165가 비슷한 행을 더했으면 그것을 쓴다.
- 시간 표기는 `useTime()`을 쓴다(0162 영어 단위).

## 완료 조건

- 시험: Queued, Running, Waiting for Input, Paused, Disconnected, 끝난 런(Succeeded·Failed·Canceled). PR 없음, Open+CI 실패+충돌+뒤처짐, Merged, 못 읽음. 취소 중. 자세히 보기 일반 클릭과 수정키 클릭, PR 버튼 새 탭.
- 스크린숏: 시안 After 두 경우. 가상 데이터. 1440 폭 다크.
- DB 변경 없음. two-way.
