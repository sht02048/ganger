# 0176 Tickets 한 번에 할당과 묶기 보기 다듬기

## 배경

0171·0172 머지 뒤 리뷰에서 남은 항목이다. 운영자가 2026-11-22에 아래 결정을 승인했다.

## 결정

1. 선행 티켓을 다 읽을 때까지 할당 버튼을 막고 "선행 티켓 확인 중…"으로 보인다. 체크 상자는 계속 바꿀 수 있다.
2. 선행 티켓 읽기가 실패한 하위 티켓은 처음에 체크하지 않고 "선행 티켓을 읽지 못했어요"를 안내한다. 사람이 체크하면 할당할 수 있다. 모든 읽기가 끝나면(성공·실패) 버튼이 풀린다.
3. 지난 런이 Failed·Canceled인 하위 티켓도 선행 티켓을 읽고 할당 전 티켓과 같은 안내를 보인다. 처음 체크하지 않는 기본값은 그대로다.
4. 가운데 단계 상위 이슈에도 맨 위 이슈와 같은 규칙을 쓴다. 자기 런만 거르기에 맞으면 묶기 보기에서 숨기고, 그 아래 맞는 하위 티켓은 그대로 보인다. 모든 티켓 보기와 거르기 개수에는 남는다.

대화상자가 열린 뒤 다시 읽기로 새로 할당할 수 있게 된 하위 티켓도 읽는다.

## 범위 밖

- 서버 할당에 선행 검사를 더하는 일. 0171 결정과 같이 웹 화면 버튼만 막는다.
