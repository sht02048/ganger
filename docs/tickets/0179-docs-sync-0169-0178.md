# 0179 0169–0178 뒤 문서 맞추기

0169–0178 머지 뒤 코디네이터가 문서를 점검했다(2026-11-22). ADR, GLOSSARY, 디자인 시스템 규칙, 기여 안내, 사용자 안내가 지금 화면과 어긋난 곳을 고친다. 제품 동작은 바꾸지 않고, 코드 변경은 쓰지 않는 열 토큰 지우기뿐이다.

## 운영자 결정 (2026-11-22)

- 쓰지 않는 열 토큰 `projectColumn`, `priorityColumn`, `runStatusColumn`, `runTitleMaxColumn`을 지운다.
- GLOSSARY의 처리할 일은 두 뜻을 함께 정의한다. 티켓 단위는 마지막 런이 To do인 티켓이고, 런 단위는 그 런에서 사람이 할 다음 일이다. 화면 문구는 바꾸지 않는다.

## 할 일

1. ADR 0010: 0174 갱신을 더하고 Run 상세 구조, PR 정보 위치, 남긴 워크트리 안내, 목록 + 패널을 쓰는 화면을 지금 코드에 맞춘다.
2. ADR 0007: 0173 갱신을 더한다. Runs는 러너 카드·기다리는 런 카드·끝난 런 표와 덮여 열리는 `Sheet`이고, 목록 + 상세 패널은 Tickets·Runners에 남는다.
3. `packages/ui/DESIGN.md`: Runs 구조가 바뀌어 낡은 설명을 고치고, `Dialog`의 `triggerCompact`와 0171의 크기 토큰을 더한다.
4. 쓰지 않는 열 토큰 넷을 토큰 정의와 문서에서 지운다.
5. GLOSSARY: 남긴 워크트리의 R8 예외, 상위 이슈의 할당, 처리할 일의 두 뜻을 고치고 한 번에 할당, Tickets 두 보기, 기다리는 런을 더한다.
6. CONTRIBUTING: 컴포넌트를 마운트하는 단위 시험의 jsdom 환경을 적는다.
7. `docs/guide/configuration.md`: PR이 머지되면 바꿀 트래커 상태(0170)를 적는다.
