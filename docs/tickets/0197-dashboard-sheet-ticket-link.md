# 0197 Dashboard 런 패널: 티켓을 트래커에서 여는 링크

Dashboard에서 런 카드를 눌러 연 오른쪽 패널의 「티켓」 줄은 키와 트래커 프로젝트 글자만 보이고 트래커로 가는 링크가 없었다(운영자 요청 2026-11-23). Run 상세에도 티켓 링크가 없었다.

## 운영자 결정 (2026-11-23)

1. Dashboard 런 패널의 「티켓」 줄에 트래커에서 여는 링크를 더한다. Tickets 패널과 같은 `ExternalIconLink`, 같은 문구, 새 탭이다.
2. Run 상세도 같은 링크를 쓴다.
3. 주소는 화면을 읽을 때 미리 가져오지 않고 누를 때 알아낸다. 읽기 캐시는 Tickets·Settings를 읽을 때만 채워지고 5분 뒤 만료돼 Dashboard 링크의 근거가 되지 못한다. 캐시·DB·worker는 바꾸지 않는다.
4. 모바일이 쓰는 티켓 주소 읽기(런 → 트래커 연결 → `getTicket` → `isWebUrl`)를 공용 함수로 꺼내고, 웹 경로 `/runs/<runId>/ticket`이 트래커 주소로 302 리다이렉트한다. v1 동작과 응답은 그대로다.
5. 리다이렉트 대상은 `isWebUrl`을 통과한 https 주소만 허용한다.
6. 찾지 못하거나 트래커에 닿지 않으면 짧은 안내 페이지를 보인다.

## 완료 조건

- [x] 주소 있음은 302, 티켓 없음·웹 주소 아님·http 주소는 404 안내, 트래커 실패는 503 안내다.
- [x] Dashboard 패널과 Run 상세의 링크가 새 탭으로 열리고 접근 이름을 가진다.
- [x] v1 티켓 링크 시험과 기존 Dashboard 시험이 그대로 통과한다.
- [x] 링크가 보이는 패널 스크린숏을 PR에 싣는다.
