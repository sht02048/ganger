# 0184 끝난 런에 PR 번호 링크를 같은 말로

## 배경

운영자 보고(2026-11-22): 같은 Succeeded 런이 화면마다 다르게 보인다. Tickets 목록은 PR이 머지된 줄만 "PR #138 머지"로 바뀌고, 상위 이슈 패널의 하위 티켓 목록은 "Succeeded", 마지막 런 카드는 "PR #138 병합됨", Runs 끝난 런 표는 "끝남 · PR 병합됨"이다.

## 결정

- 요약 결과 표시는 그대로 두고, PR이 있으면 뒤에 " · PR #138"을 붙인다. PR 상태 낱말은 붙이지 않는다. PR이 열림·닫힘이어도 같은 모양이고, 없으면 아무것도 붙이지 않는다.
- PR 번호는 PR로 가는 링크이고 새 탭으로 연다.
- 적용 자리: Tickets 목록 런 칸, 상위 이슈 패널의 하위 티켓 줄, Runs 끝난 런 표 상태 칸.
- 티켓 패널 마지막 런 카드는 PR 상태를 말하는 유일한 자리로 남아 "PR #138 병합됨"을 유지하고 번호만 링크로 바꾼다.
- 줄 전체가 눌리는 행 안의 링크는 행 누름과 겹치지 않는다. 링크 클릭은 링크만 열고, 키보드 Tab으로 닿는다.

## 완료 조건

- [x] 단위: 세 자리 각각 PR 있음(머지·열림·닫힘)/없음, 링크 href, 행 누름과 링크 누름이 따로.
- [x] 브라우저: Tickets 목록과 Runs 끝난 런 표에서 PR 링크가 새 탭으로 열리고 행 선택은 바뀌지 않는다.
- [x] 쓰지 않게 된 문구 키를 지우고 ADR 0010을 맞춘다.
- [x] 스크린숏: Tickets 목록 런 칸, Runs 끝난 런 표.
