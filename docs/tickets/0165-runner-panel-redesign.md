# 0165 Runners 상세 패널 다시 짜기

## 목표

운영자가 Tickets 패널에 이어 Runners 상세 패널도 다시 짜기로 했다(2026-11-21). 지금 패널은 상태 알약이 이름보다 위에 있다. 자리의 런은 번호와 제목 두 줄로 흩어진다. 사용량은 "가장 높은 사용량"과 긴 글 목록이다. 확인 항목은 모두 통과해도 줄마다 다 보이고, 다시 확인 버튼은 확인 항목 아래에 숨어 있다. 운영자가 시안(After 두 보드)을 골랐다.

## 결정 (시안대로)

- **머리.** 첫 줄은 러너 이름(제목)과 ssh 주소(고정폭 작은 글)이고, 오른쪽에 "고치기" 연필 아이콘 버튼(`aria-label` "{name} 러너 고치기", 지금 편집 흐름 그대로)을 둔다. 둘째 줄은 상태 알약, "N min ago 확인", 오른쪽 끝 "다시 확인" 버튼이다. 다시 확인 진행·결과 문장(`role="status"`)은 이 줄 아래에 둔다. 확인 항목 아래 다시 확인 버튼은 없앤다.
- **고칠 일 카드.** Offline·Runner Issue이거나, 상태가 Online이어도 push가 깨진 저장소(`pushBlockedProjects`)가 있으면 나온다. 이때 상태 알약은 Online 그대로다(코디네이터 결정 2026-11-21). 확인 항목이 깨졌으면 무엇이 깨졌는지(가장 먼저 깨진 항목 이름), 영향(어떤 저장소 티켓을 맡기지 않는지), 고치는 법(그 항목의 안내, 명령은 code), 강조 "다시 확인" 버튼을 둔다. 이때 머리 줄의 다시 확인 버튼은 숨겨 버튼이 하나만 보인다. Offline이면 지금 단계 안내를 이 카드 모양으로 둔다.
- **자리.** "자리 N/M" 아래에 칸 막대(칸마다 하나, 쓰는 칸은 Running 색)를 두고, 지금 하는 런은 한 줄 행(상태 점, 번호, 제목 말줄임, 오른쪽 시간 또는 To do 종류)으로 보인다. 누르면 그 런을 연다. 이 러너를 기다리는 Queued 런은 "이 러너를 기다리는 Queued 런 N · 번호들" 한 줄로 보인다. 자리가 0개(무제한 등)면 막대를 빼고 지금처럼 숫자만 보인다.
- **사용량.** 구역 이름은 "사용량"이고 옆에 ⓘ 툴팁("계정 정보는 저장하지 않아요."), 오른쪽에 "N min ago 읽음"을 둔다. 공급자마다 이름 아래 창별 행(창 이름, 막대, %)을 둔다. 한도에 닿은 창은 문제 색이고, 초기화 시각은 그 행의 툴팁 또는 막대 아래 작은 글로 둔다(구현하며 고르고 PR 본문에 적는다). 로그인하지 않았거나 쓰지 않는 공급자는 지금 문장 한 줄이다. "가장 높은 사용량" 묶음은 없앤다. Runners 목록 행의 가장 높은 사용량 표시는 바꾸지 않는다.
- **확인 항목.** 모두 통과하면 "N개 모두 통과" 한 줄 접힘(펼침 버튼, `aria-expanded`)으로 둔다. 하나라도 깨졌거나 모르면 펼친 목록으로 두고 깨진 항목을 맨 위에 둔다(지금 순서 규칙). 줄마다 아이콘(통과·깨짐·모름이 모양으로도 다름)과 이름, 깨진 줄은 오른쪽에 이유를 둔다. GitHub push는 저장소마다 한 줄이다.
- **남은 워크트리.** "남은 워크트리 N" 아래 한 줄 행(번호, 이유)으로 둔다.
- **간격·모양.** 구역 사이는 구역 안 간격의 두 배 이상이다. 둥글기는 카드 12px, 행·버튼 8px, 알약 6px(ADR 0010)이다. 칸 막대·한 줄 행·접힘 행이 `packages/ui`에 없으면 거기에 더한다. 0164(Tickets 패널) 워커가 같은 종류의 행·칩을 더하고 있을 수 있으니, develop에 먼저 들어온 것이 있으면 그것을 쓴다.
- 시간 표기는 `useTime()`을 쓴다(0162가 영어 단위로 바꾸는 중이다).
