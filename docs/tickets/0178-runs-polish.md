# 0178 Runs 다듬기

0173·0174 머지 뒤 리뷰에서 남은 항목이다. 운영자가 2026-11-22에 아래 결정을 승인했다.

## 할 일

1. 런 하나 읽기: Runs 패널은 그 티켓의 런만 읽어 `superseded`를 계산하고, Queued 런일 때만 큐 이유를 읽는다. 결과 값은 목록 경로와 같다.
2. 패널 링크: 처리할 일과 이어서 맡기기 링크는 전체를 다시 불러오지 않고 런 상세로 간다. 수정키 클릭은 그대로 새 탭으로 연다.
3. 답을 남긴 질문(Q5): 아직 에이전트에게 전하지 않은 답은 "답을 보냈어요", 권한 거절은 "거절했어요"로 보인다. 둘 다 "답을 기다려요" 수에서 빼고 맨 위에 올리지 않는다. 패널 본문도 같은 사실을 말한다.
4. Queued 이유(Q6): 카드 제목은 "기다리는 런"이고 줄마다 짧은 이유를 보인다. 상황 문장도 맞게 고친다.
5. 취소 중(Q7): 취소를 요청한 런은 회색 점과 "취소 중"으로 카드 맨 아래에 두고 상황 수에서 뺀다. 끊긴 런이라도 취소 중이면 취소 안내를 먼저 보인다.
6. 다른 Workspace 러너(Q8): Runners의 "Runs에서 보기"는 러너의 런이 한 Workspace에만 있으면 그 Workspace로 간다. Runs 러너 카드의 다른 Workspace 문장은 한 곳이면 링크이고, 나뉜 러너에도 보인다. 런 상세의 러너 링크는 그 런의 Workspace를 쓴다.
7. 좁은 화면 탭 순서(Q9): 기다리는 런 카드를 DOM에서 러너 카드 앞에 두고 넓은 화면 배치는 그대로 둔다.

## 완료 조건

- 단위 시험이 1~7을 각각 확인한다. 1은 목록 경로와 단일 경로가 같은 `BoardRun`을 내고 단일 경로가 다른 티켓 런을 읽지 않는지 본다.
- 브라우저 시험 `e2e/src/runs-polish.test.ts`가 패널 링크의 문서 유지와 좁은 화면 Tab 순서를 확인하고, 부하 아래 5회 통과한다.
- 스크린숏: 답을 보냈어요·취소 중이 있는 러너 카드, 이유가 달린 기다리는 런 카드, 다른 Workspace 링크 카드.
