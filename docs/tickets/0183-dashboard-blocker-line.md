# 0183 Dashboard 카드에서 선행 티켓을 두 번 말하지 않기

Dashboard Queued 칸 카드(0160)는 선행 티켓 칩(예: ACME-11, 취소선 ACME-9)을 보이면서 아랫줄에 "ACME-11을 기다려요"를 한 번 더 말한다. 멈춘 카드도 칩 "ACME-10 취소"와 아랫줄 "선행 티켓 ACME-10이 취소됐어요"가 겹친다(운영자 보고 2026-11-22).

## 운영자 결정 (2026-11-22)

1. 칩이 보이는 Queued 카드의 아랫줄은 티켓 키 없이 원인만 말한다. 어느 티켓인지는 칩이 말한다.
2. 취소 중, Workspace 이름 등 아랫줄의 다른 조각은 그대로 둔다.
3. 칩이 없는 Queued 카드("곧 시작해요", "빈 러너를 기다려요" 등)는 그대로 둔다.
4. 칩, 빨간 테두리, 시간은 그대로 둔다.
5. 다른 화면(Runs 기다리는 런 카드, Tickets 목록, 알림 등)의 `blockers-waiting` 문장은 바꾸지 않는다.

## 문장

| 까닭      | 아랫줄                    |
| --------- | ------------------------- |
| 기다림    | 선행 티켓을 기다려요      |
| 취소      | 선행 티켓이 취소됐어요    |
| 읽지 못함 | 선행 티켓을 읽지 못했어요 |
| 순환      | 선행 티켓과 서로 기다려요 |

## 결정

- 칩은 이미 카드 버튼의 `aria-describedby`에 들어가 키와 상태 이름이 화면 읽기 프로그램에 전해진다. `packages/ui`는 고치지 않는다.
- 기다리는 선행 티켓이 없고 끝난 선행 티켓 칩만 있는 값은 "선행 티켓을 기다려요"가 사실이 아니므로 기존 문장을 쓴다.

- [x] 브라우저: Dashboard 기다리는 카드와 멈춘 카드가 새 문장을 보인다.
