# 0112 모바일 9: TestFlight 배포

## 목표

iOS 앱을 데스크톱 앱과 같은 Apple 개발자 팀으로 서명해 TestFlight 외부 테스트로 배포한다. 심사관은 앱 안 데모 모드로 모든 화면을 본다(스펙 [0002](../spec/0002-mobile.md) 9절, M7).

## 범위

- 배포용 서명(0109의 개발 빌드 서명을 넓힌다)과 TestFlight 빌드·제출 방법. 서명 값, 팀 ID, 키는 저장소에 두지 않는다.
- 심사용 데모 모드 진입과 심사 메모.
- 배포 절차 문서(영어, 사용자 문서).
- 지금 출시 흐름과의 관계를 정해 적는다. 브랜치는 ADR 0017을 따른다. `release.yml`은 `v*` 태그로 돌고 서명 비밀 값은 `release` environment에 있으며, 버전 파일은 루트와 `apps/desktop`이다(`scripts/release-version.ts`). 모바일 빌드가 데스크톱 출시에 끼어들지 않게 하고, `bundle`·`smoke:bundle`에 모바일이 들어가지 않는 것을 확인한다.
- 앱의 최소 서버 버전(M27)을 출시 때 어떻게 올릴지 적는다.
- 배포는 운영자가 말할 때만 한다.

## 완료 조건

- 운영자가 말한 때에 TestFlight 빌드를 올리고, 데모 모드 진입 방법을 담은 심사 메모와 함께 외부 테스트 심사에 제출한다.
