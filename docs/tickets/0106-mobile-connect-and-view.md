# 0106 모바일 3: 앱에서 서버에 연결하고 보기

## 목표

앱에서 Ganger 화면의 QR을 읽어 서버에 연결하고, 실제 서버의 Dashboard·Runners·설정을 본다. 앱에서 이 기기의 연결을 끊을 수 있다(스펙 [0002](../spec/0002-mobile.md) 1절 첫 완료 기준).

## 범위

- QR 읽기 → 연결 코드로 토큰 받기 → 토큰을 기기의 안전한 저장소에 두기.
- 데모 모드 화면(0105)을 `/api/v1` 읽기로 바꾼다. 처음 열면 처리할 일이 있는 칸부터 보인다. Workspace 고르기를 넣는다.
- Runners와 설정 화면에 필요한 v1 읽기를 더한다(0104의 계약을 넓힌다).
- 설정: 연결한 서버와 연결 상태, 이 기기 연결 끊기, 앱 버전.
- 토큰이 거절되면(기기를 지웠으면) 연결 화면으로 돌아간다.
- Host가 허용되지 않은 403(티켓 0157 F7·F8)은 토큰 거절과 갈라, 연결을 지우지 않고 서버 맥의 Settings › 주소를 고치라고 안내한다. 403 본문에는 이유 값이 없어 데스크톱 앱처럼 `/api/identity`의 `webAccess`로 가린다.
- 서버에 닿지 않으면 마지막 내용을 "n분 전 기준" 띠와 함께 보이고 행동 버튼을 끈다. 오프라인 쓰기 대기열은 없다(M31).
- 개발 연결(M45): 개발 빌드는 QR 없이 `pnpm dev:mobile`의 로컬 서버에 자동 연결한다. 개발용 기기 토큰은 dev 서버가 발급하고, 연결 정보는 `GANGER_DESKTOP_DEV_SERVER`처럼 환경 변수로 받는다. 제품 앱은 `demo/`를 import 하지 않는다.
- 화면 갱신(M26): 변경 기록 SSE를 v1 아래에 기기 토큰 인증으로 열고, 앱이 앞에 있을 때만 붙는다. 실패하면 폴링한다.
- 버전 호환(M27): 앱에 최소 서버 버전을 두고 v1 응답의 서버 버전·계약 버전과 맞지 않으면 안내한다.
- "처리할 일만"과 세그먼트 배지는 티켓 단위 To do로 센다(M30). 멈춘 기다림, 보고 없이 멈춘 Paused, PR CI 실패는 보이기만 한다(M29).

## 운영자 결정

- 시뮬레이터는 `127.0.0.1`의 평문 http dev 서버에 붙고, 개발 빌드에만 `NSAllowsLocalNetworking` ATS 예외를 둔다(출시 빌드에는 없다). 실기기 개발 빌드는 tailnet HTTPS(`tailscale serve`)로 붙어 예외가 필요 없다. LAN IP + http는 쓰지 않는다(스펙 0002 M46).

## 범위 밖

- 쓰기(0107), 알림 켜기와 푸시(0109).

## 완료 조건

- 실기기에서 HTTPS의 다른 기기에서 열 주소(예: Tailscale Serve)를 둔 `pnpm dev` 서버에 QR로 연결해 Dashboard·Runners·설정을 보는 과정을 PR에 남긴다(스크린숏). 시뮬레이터에는 카메라가 없으므로 QR 내용을 붙여 넣는 개발용 길을 둘 수 있다.
- 연결 끊기와 지운 기기의 거절을 앱이 처리하는 시험이 있다.
- Host 403을 토큰 거절과 갈라 안내하고 연결을 지우지 않는 시험이 있다.
- 기기 토큰 없는 v1 변경 기록 SSE가 거절되고, 지운 기기의 연결이 닫히며, SSE가 실패하면 앱이 폴링으로 넘어가는 시험이 있다.
- 최소 서버 버전보다 낮은 서버를 앱이 안내하는 시험이 있다.
- 서버에 닿지 않으면 "n분 전 기준" 띠가 보이고 행동 버튼이 꺼지며 쓰기가 쌓이지 않는 시험이 있다.
- 개발 빌드가 환경 변수의 dev 서버에 QR 없이 연결하고, 제품 빌드에서는 이 길이 꺼지는 시험이 있다.
