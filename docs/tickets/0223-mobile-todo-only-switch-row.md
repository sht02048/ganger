# 0223 모바일 Dashboard "처리할 일만" 스위치 자리 바로잡기

## 배경

운영자가 2026-11-25에 실기기 데모로 본 Dashboard 의 "처리할 일만" 줄이 어색하다. 라벨은 왼쪽 끝, 스위치는 오른쪽 끝에 떨어져 있고, 위아래 줄과 같은 열·가운데 정렬도 아니다.

`apps/mobile/src/dashboard/dashboard-screen.tsx` 는 세그먼트 아래에 개수 줄(`countLine`, `Text` `small`)을 두고, 그 아래에 설정 화면용 `SwitchRow`(이름은 `flex: 1`, 스위치는 오른쪽 끝)를 따로 둔다.

## 결정

운영자가 2026-11-25에 코디네이터 제안을 골랐다. 개수 줄과 "처리할 일만" 스위치를 한 줄로 합친다. 왼쪽에 개수 줄, 오른쪽에 "처리할 일만" 이름과 스위치를 붙여 같은 높이 가운데로 맞춘다. 세그먼트와 카드 목록의 좌우 가장자리에 맞추고, 이름을 눌러도 스위치가 바뀐다.

## 할 일

1. 모바일 디자인 시스템에 줄 안에 두는 `InlineSwitch` 를 더한다. 이름과 스위치를 한 `Pressable` 로 묶어 접근 이름은 이름, 역할은 `switch`, 상태는 `aria-checked` 다. 누르는 곳은 최소 44 다. 안의 네이티브 스위치는 누름과 화면 읽기에서 빼서 한 번 눌러 한 번만 바뀌게 한다. 설정 화면의 `SwitchRow` 는 그대로 둔다.
2. `dashboard-screen.tsx` 에서 개수 줄과 `InlineSwitch` 를 `flexWrap` 줄 하나로 합친다. 개수 줄은 남는 너비를 차지하고, 글이 길거나 큰 글자(Dynamic Type)면 스위치가 다음 줄 오른쪽으로 내려간다.
3. 모바일 `DESIGN.md` 컴포넌트 표와 스펙 0002 Dashboard(M18) 설명에 이 줄을 적는다.

## 남은 위험

- 줄 바꿈과 큰 글자에서의 모양은 jsdom 시험으로 확인할 수 없다. 실기기 확인은 머지 뒤 운영자가 한다.
- Expo web 에서는 숨긴 체크박스가 탭 이동 대상으로 남는다. 앱은 iOS 전용이고 Expo web 은 개발·시험용이다.

## 완료 조건

- 모바일 화면 시험: "처리할 일만" 스위치가 개수 줄과 같은 줄에 있고, 접근 이름이 "처리할 일만" 이며, 이름 글자를 눌러도 켜지고 꺼진다.
- 디자인 시스템 시험: `InlineSwitch` 는 화면 읽기에 스위치 하나로 읽히고, 스위치를 눌러도 한 번만 바뀌며, 꺼져 있으면 바뀌지 않는다.
