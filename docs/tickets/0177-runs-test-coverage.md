# 0177 Runs·런 상세 시험 보강

## 배경

0173·0174 머지 뒤 리뷰에서 시험 공백이 남았다. 운영자가 2026-11-22에 보강을 승인했다. 제품 코드는 바꾸지 않는다.

## 할 일

1. 얇은 경로 시험이 런 패널을 다시 렌더 결과로 확인한다. 패널은 서버 HTML에 없는 대화상자라 브라우저로 `/runs?view=all&sel=<runId>`를 열어 티켓 키, 결과 낱말, 에이전트 결과, PR 구역 문장, PR이 있을 때만 `#pr`을 본다. 끝난 런 표 줄의 결과 낱말 확인도 둔다.
2. `runs`, `runs-query`, `run-detail`, `run-action-dedupe` 시험의 `networkidle` 대기를 그 자리가 실제로 기다리는 화면 조건으로 바꾼다.
3. 런 상세의 문제 띠가 `pr-conflict`, `pr-ci-failed`(`checkTotal: null`)이고 보존 워크트리가 없으면 빈 본문을 두지 않음을 구조로 확인한다. 보존 워크트리가 있으면 본문이 있는 경우를 대조한다.

## 완료 조건

- 바꾼 e2e 파일이 CPU 부하 프로세스 4개 아래에서 5번 모두 통과한다.
- 패널에서 PR 구역 문장을 빼면 얇은 경로 시험이 실패한다.
- 빈 본문 수정을 되돌리면 새 단위 시험이 실패한다.
