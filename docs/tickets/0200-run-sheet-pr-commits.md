# 0200 런 패널 「PR」 탭 커밋 내역

Dashboard 런 패널의 「PR」 탭(0199)에서 PR에 어떤 커밋이 올라갔는지 보이게 한다.

## 운영자 결정 (2026-11-23)

1. PR의 커밋을 모두 받아 온다(GitHub GraphQL, 100개씩 페이지). PR 신호와 같은 주기로 다시 읽는다.
2. 「PR」 탭 맨 아래에 「▸ 커밋 N개 · 마지막 n분 전」 한 줄로 접어 둔다. 위 구분선은 없고 아래 구분선만 둔다. 누르면 그 자리에서 전부 펼친다.
3. 목록만 따로 스크롤되는 상자는 없고 패널 전체가 스크롤된다.
4. 최근 것이 위다. 한 줄에 메시지 첫 줄(넘치면 줄임표, 마우스를 올리면 전체), 짧은 SHA, 작성자, 시각을 둔다. 누르면 그 커밋의 GitHub 페이지를 새 탭으로 연다.
5. 저장이 새 표·열을 요구하면 운영자 승인을 받는다.

## 완료 조건

- [x] 페이지를 넘겨 모든 커밋을 읽는 시험.
- [x] 접힘·펼침, 순서, 줄임표와 전체 글, 새 탭 링크 시험.
- [x] 커밋이 많은 PR의 「PR」 탭 스크린숏.
