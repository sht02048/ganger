# 0170 PR이 머지되면 트래커 티켓 상태 바꾸기

## 배경

Ganger는 런이 시작될 때만 트래커 티켓 상태를 바꾸고, PR에 따른 상태는 Linear의 GitHub 연동에 맡겼다([ADR 0001](../adr/0001-tracker-is-source-of-truth.md)). 이 연동이 없는 환경도 있어, 운영자가 2026-11-22에 선택 설정을 더하기로 했다.

## 할 일

- 트래커 프로젝트 설정에 "PR이 머지되면 바꿀 상태"를 더한다. 처음 값은 "바꾸지 않음"이고 그때는 지금과 똑같이 동작한다.
- worker가 런의 PR 머지를 확인한 때 티켓을 고른 상태로 런마다 한 번 바꾸고, 바꾼 시각을 런 기록에 적는다.
- Settings 트래커 프로젝트 화면에 "트래커 티켓 상태" 구역을 두고 시작 때 상태와 머지 때 상태를 함께 보여 준다.
- ADR 0001과 GLOSSARY의 Run 항목을 맞춘다.

## 동작 규칙

- PR이 머지 없이 닫혔거나, PR이 없거나, "바꾸지 않음"이면 바꾸지 않는다.
- 트래커 호출이 실패하면 다음 tick에 다시 시도하고, 워크트리 정리를 막지 않는다.
- 트래커가 not-found를 돌려주면 더 시도하지 않는다. 고른 상태가 지워진 경우와 구분되지 않아, 티켓이 사라졌다고 기록하지 않고 결과 댓글은 그대로 시도한다.
- 머지 상태로 바꾼 런은 실패했던 시작 상태 바꾸기를 다시 하지 않는다.
- 런이 끝나기 전에 머지돼도 머지를 확인한 때 바꾼다. 같은 티켓에 런이 여럿이면 각 런의 PR 머지 때마다 적용한다.
- 머지를 새로 확인한 때만 바꾼다. 설정을 고르기 전에 이미 머지된 지난 런의 티켓은 바꾸지 않는다.
- 재시도 대기는 worker 메모리에 둔다. 머지를 확인한 뒤 상태를 바꾸기 전에 worker가 다시 시작되면 그 런은 다시 시도하지 않는다.

## DB 마이그레이션
