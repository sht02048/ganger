# 0186 Dashboard Done 칸: 머리로 Runs 이동, 최대 5개

## 배경

운영자 요청(2026-11-22): Dashboard Done 칸의 "처리할 일 없이 끝났어요" 묶음 아래 "Runs에서 모두 보기" 링크를 없애고, Done 칸 머리를 누르면 Runs로 가게 하며, 처리할 일 없이 끝난 카드는 최대 5개만 보인다.

## 운영자 결정 (2026-11-22)

1. "Runs에서 모두 보기" 링크와 그 문구 키를 없앤다.
2. Done 칸 머리(제목과 개수)를 Runs 링크로 만든다. 0181의 앱 안 이동 규칙을 따라 일반 클릭은 라우터 이동, 수정 키 클릭은 새 탭이다. Queued·Running 칸 머리는 그대로다.
3. 처리할 일 없이 끝난 카드는 최대 5개다. 넘으면 숨기고 더 보기 버튼을 두지 않는다. 시트로 연 카드가 숨은 범위에 있으면 그 카드는 보인다.
4. Done 칸의 처리할 일 카드(`DONE_TODO_VISIBLE`)는 바꾸지 않는다.
5. 링크는 `/runs?ws=<id>&view=all`이다. Done 칸과 Runs 기본 기간이 같은 달력 7일이라 기간 인자를 담지 않는다.

## 완료 조건

- [x] 단위 시험: 링크 사라짐, 머리 링크 href·접근 이름, 6개 이상일 때 5개만
- [x] 브라우저 시험: 머리 클릭은 문서를 다시 불러오지 않고 Runs로, ⌘클릭은 새 탭, 숨은 카드를 시트로 열면 보임
- [x] 새 브라우저 시험을 CI와 비슷한 부하에서 5번 통과
- [x] 스크린숏: Done 칸(머리 링크 hover, 5개)

## 결정

- 모든 Workspace 보기의 머리 링크는 `/runs`다. Runs는 Workspace 하나만 보여 주므로 ws 없는 `/runs`는 첫 Workspace를 연다.
- 7일보다 오래된 Failed 꼬리표 카드는 Done 칸 개수에 들지만 Runs 기본 기간에는 없다.
