# 0171 상위 이슈로 묶는 Tickets 화면

## 배경

운영자가 2026-11-22에 Tickets 화면이 Runs 화면과 너무 비슷하다고 짚었다. 둘 다 키·제목 표에 런 상태 알약이다. 티켓은 Linear의 상위 이슈·하위 이슈 관계대로 묶여 보여야 한다. 하위 티켓을 한 번에 할당하는 일은 후속 티켓 0172가 맡는다.

## 할 일

### 읽기

- Linear 이슈를 읽을 때 상위 이슈(키·제목·id)를 함께 받는다. 3단계까지 따라 올라가고, 더 깊으면 찾은 가장 위 이슈로 묶는다.
- 상위 이슈가 읽은 범위 밖이면 하위에 딸려 온 정보만으로 묶음을 만든다. 진행 수는 읽어 온 하위 티켓만 센다. 패널에는 안내와 Linear 링크만 둔다.
- Tickets 화면에서는 하위 티켓이 있는 상위 이슈에 할당 버튼을 두지 않는다. 하위가 없는 이슈는 지금처럼 할당한다. 웹 할당 서버 함수, MCP 할당, 라벨 자동 할당은 바꾸지 않는다(운영자 결정 2026-11-22).

### 보기

- 거르기 줄 끝에 아이콘 버튼 두 개: 상위 이슈로 묶어 보기(기본), 티켓 하나씩 보기. 고른 보기는 URL search param으로 기억하고 기본값이면 생략한다. 보기·거르기·찾기는 서로 유지한다.
- 모든 줄은 [상태 아이콘][키][제목][런][할 일] 다섯 칸이다. 하위 줄은 아이콘만 안쪽으로 들어간다.
- 상태 아이콘은 Linear 상태 분류로 모양을 고르고 색은 Ganger 토큰으로 고정한다. 상태 이름은 툴팁과 접근 이름이다.
- 상위 이슈 줄은 펼치기 버튼, 진행 고리, 굵은 제목, 작은 "2/5"를 보인다.
- 런 칸은 마지막 런을 점과 상태 이름으로, 상위 이슈는 하위 런 요약으로 보인다. 상위 이슈 자기 런이 끝나지 않았으면 요약보다 먼저 보이고, 사람이 볼 일 판정에도 넣는다(운영자 결정 2026-11-22). 할 일 칸은 테두리 버튼 하나를 할 일이 있을 때만 둔다.
- 좁은 화면에서는 런 칸을 숨기고 그 정보를 제목 아래 한 줄로 옮긴다.

### 묶기 보기

- 묶음 순서: 사람이 볼 일 → 할당할 수 있는 하위 → 진행 중 → 모두 끝남, 같은 단계는 최근 수정 순, "상위 이슈 없음"은 맨 아래.
- 하위가 모두 Done인 묶음은 접고 나머지는 펼친다. 펼침 상태는 기억하지 않는다.
- 거르기는 맞는 하위만 보이고 상위 줄을 남긴다. 진행 수는 전체 기준이다. 찾기는 상위가 맞으면 묶음 전체, 하위만 맞으면 상위 줄과 맞는 하위다.

### 모든 티켓 보기

- 같은 줄 규칙으로 한 줄에 티켓 하나를 보이고, 상위 이슈는 제목 아래 작은 줄로 보인다.

### 상위 이슈 패널

- 머리, 하위 티켓 진행, 하위 티켓 목록, 티켓 정보, 자기 런이 있으면 런 구역을 둔다.
- 하위 티켓 패널은 지금 패널에 상위 이슈 링크 한 줄을 더한다.

### 문서·MCP

- GLOSSARY에 상위 이슈·하위 티켓을 더한다. ADR 0010에 갱신 문단을 더한다.
- MCP 티켓 출력에 상위 이슈 키와 제목을 더한다. 사용자 문서를 맞춘다.

## 범위 밖

- Dashboard·Runs·Run 상세, 한 번에 할당(0172), Linear 팀 상태 색.

## 구현 결정

- 3단계 위는 Linear에 더 묻지 않고, 읽어 온 모든 티켓의 상위 사슬을 이어 같은 묶음으로 합친다.
- 중간 단계 이슈도 맨 위 이슈 묶음의 하위 줄로 펼쳐 보이고 진행 수에 넣는다. 그 이슈도 하위가 있어 화면에 할당 버튼을 두지 않는다.
- 묶음 안 하위 티켓과 "상위 이슈 없음" 티켓은 묶음과 같은 단계 규칙, 같은 단계 안에서는 최근 수정 순으로 둔다.
- 진행 수의 분모에서 Canceled를 뺀다. 하위가 모두 Done이거나 Canceled면 끝난 묶음으로 접는다.
- 트래커에서 끝난 티켓은 지난 런이 Failed여도 끝난 단계로 센다. 런이 아직 끝나지 않았으면 트래커 상태와 상관없이 사람이 볼 일이나 진행 중으로 센다.
- 상위 이슈 자기 런만 거르기에 맞으면 묶기 보기에서는 묶음을 숨긴다. 거르기 개수에는 그대로 들어가고, 모든 티켓 보기에서 보인다.
- 거르기나 찾기를 쓰는 동안에는 끝난 묶음도 펼쳐 맞는 하위를 보이고, 거르기나 찾는 말이 바뀌면 손으로 접은 기록을 지운다.
- 행 안에 펼치기·할 일 버튼을 두려고 Tickets 목록은 listbox 대신 목록과 제목 버튼으로 만들고, 화살표·Home·End 이동을 유지한다.
- 가상 스크롤은 행마다 잰 높이의 누적 위치로 보이는 행을 고른다.
