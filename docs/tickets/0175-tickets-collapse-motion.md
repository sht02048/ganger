# 0175 Tickets 상위 이슈 펼치고 접기 움직임

## 배경

운영자가 2026-11-22에 Tickets 묶기 보기에서 상위 이슈를 펼치고 접을 때 움직임이 없다고 짚었고, 시안 3안 중 B안을 골랐다.

## 할 일

- 묶음 높이는 열 때 220ms, 닫을 때 160ms, `easeOut`으로 `grid-template-rows` 0fr↔1fr을 옮긴다. 아래 묶음은 높이 변화를 따라 밀려난다.
- 펼침 버튼 화살표는 150ms 회전한다.
- 하위 줄은 열 때 30ms 간격으로 위에서 4px 내려오며 200ms에 나타나고, 닫을 때는 한꺼번에 120ms에 흐려진다.
- 차례로 나타나는 효과는 처음 8줄까지다. 9번째 줄부터는 8번째 줄과 함께 나타난다. 하위 티켓이 30개를 넘는 묶음은 높이 움직임만 쓴다.
- 펼치는 중 다시 누르면 그 자리에서 되돌아간다(CSS transition).
- `prefers-reduced-motion`에서는 높이·위치가 바로 바뀌고 화살표 방향만 바뀐다.
- 처음 그릴 때와 거르기·찾기로 묶음이 바뀔 때는 움직이지 않는다. 펼침 버튼을 눌렀을 때만 움직인다.
- 움직이는 동안 가상 스크롤의 줄 위치 계산과 선택 줄 스크롤 유지가 깨지지 않게 한다.
- 움직임 토큰은 `packages/ui`에 두고 `apps/web`에서 직접 import 하지 않는다.

## 완료 조건

- 단위 시험: 줄 효과 지연(8줄 상한, 30개 초과 끔), reduced-motion 분기, 처음 그릴 때·거르기 바뀔 때 움직임 없음.
- 브라우저 시험: 펼치고 접기와 `aria-expanded`, 펼치는 중 다시 누르기, 선택 줄 유지. 부하 5회 통과.
- `/ds` 예시와 `DESIGN.md`를 갱신한다.
