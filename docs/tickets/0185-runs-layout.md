# 0185 Runs 배치 다듬기

## 배경

운영자 보고(2026-11-22), 데모 1280·1600·1920px에서 확인했다.

- 러너 카드 칸이 `auto-fill`이라 카드가 3장이어도 빈 칸이 남는다. 카드가 256px 근처에 머물러 제목이 몇 글자만 남고, 기다리는 런 카드 앞이 크게 빈다.
- 기다리는 런 줄은 오른쪽에 "선행 티켓을 기다려요 · 45 min" 같은 긴 글을 붙여 제목이 더 잘린다.
- 끝난 런 거르기 줄과 표 사이에 간격이 없다.

## 결정 (운영자, 2026-11-22)

- 러너 카드 칸은 `auto-fit`이고 최소 폭은 320px이다. 카드가 남는 폭을 나눈다.
- 러너가 1~2대일 때 카드가 지나치게 넓어지지 않게 최대 폭 560px을 둔다. 1600px 창에서 카드 2장이 칸을 채우는 값이다. 칸 묶음 전체의 폭도 카드 수만큼으로 묶어, 아주 넓은 창에서 카드 사이가 벌어지지 않고 남는 폭은 마지막 카드 오른쪽에 둔다.
- 좁은 화면(`runsBoardStacked`)은 지금처럼 한 열이고 최대 폭을 두지 않는다.
- 기다리는 런 줄은 첫 줄에 점·키·제목, 둘째 줄에 이유와 시간을 둔다. 러너 카드 줄은 한 줄 그대로다.
- `PanelListRow`에 선택 속성 `meta`(제목 아래 둘째 줄)를 더한다.
- 거르기 줄과 표 사이에 `Section` 머리 아래와 같은 `space.s3`를 둔다.
- 좁은 화면에서 기다리는 런 카드가 DOM 먼저인 순서(0178)는 그대로다.
