# 0193 Dashboard 패널: 보내기에 성공하면 패널 닫기

## 목표

Dashboard에서 "답하기"·"확인하기"로 연 오른쪽 패널은 보낸 뒤에도 닫히지 않고 폼 자리만 결과 문장으로 바뀐다(운영자 보고 2026-11-23). 보내기에 성공하면 패널을 닫고, 토스트로 결과를 알리고, 포커스를 그 런의 카드로 돌린다.

## 운영자 결정(2026-11-23)

- 대상은 질문 답하기, Human Check 답하기("확인했어요"·"고쳐 주세요"), Permission 거절이다.
- 닫을 때 토스트로 결과를 알린다. 문구는 home 메시지 파일에 해요체로 둔다.
- 포커스는 그 런의 카드로 돌린다. 카드가 다른 칸으로 옮겨졌으면 옮긴 카드, 카드가 없으면 그 칸 제목으로 돌린다.
- 서버가 거절하면(이미 답함 등) 패널을 남겨 이유를 보인다. 네트워크 오류 등 예외도 패널을 남기고 지금처럼 다룬다.
- Run 상세의 답하기와 모바일 앱은 범위 밖이다.

## 할 일

- [x] 세 종류 모두 성공하면 패널을 닫고 토스트를 띄운다.
- [x] 포커스를 카드, 없으면 칸 제목으로 돌린다.
- [x] 거절·예외는 패널을 남긴다.
- [x] 단위·컴포넌트 시험과 기존 Dashboard 브라우저 시험을 맞춘다.
- [x] 보낸 뒤 토스트가 보이는 Dashboard 스크린숏을 찍는다.

## 결정에 없던 경계 사례

- 보내는 동안 운영자가 패널을 닫고 다른 런의 패널을 열었으면, 성공해도 그 패널을 닫지 않고 토스트만 띄운다.
- 칸 제목으로 돌리는 규칙은 보내기 뒤뿐 아니라 패널을 손으로 닫을 때 카드가 없는 경우에도 적용한다.
