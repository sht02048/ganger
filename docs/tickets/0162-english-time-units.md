# 0162 시간 표기를 영어 단위로

## 목표

카드·행의 경과 시간이 1분 안에서 초 단위로 매초 바뀌어("42초째") 시선을 끌고, 하루가 넘어도 "50시간 12분째"처럼 시간으로만 늘어난다. 운영자 결정(2026-11-21)으로 모든 시간 표기를 초 없는 영어 단위로 바꾼다. 상태·칸 이름처럼 시간 단위도 영어로 쓴다.

## 결정

`useTime()`(`apps/web/src/format/time.ts`)의 모든 표기에 한 규칙을 쓴다.

| 지난 시간 | 경과·양(`elapsed`, `duration`)       | 지난 일(`ago`)               |
| --------- | ------------------------------------ | ---------------------------- |
| 1분 안    | `<1 min`                             | `Just now`                   |
| 1–59분    | `25 min`                             | `25 min ago`                 |
| 1–23시간  | `1 hr 3 min`, 분이 0이면 `2 hr`      | `3 hr ago` (지금처럼 시간만) |
| 하루 이상 | `1 day`, `2 days` (시간·분은 버린다) | 날짜 (지금 그대로)           |

- 경과의 "째"를 뺀다. 진행 중인 것은 `25 min`, 지난 일은 `25 min ago`로 구분한다. "확인하는 중이에요 · {duration}째" 같은 문장 안 경과도 같다.
- 단위는 `min`·`hr`는 복수형 없이, `day`만 `1 day`/`2 days`로 나눈다(ICU plural).
- 시각(`clock`, "10:45")과 날짜 표기, 통계 날짜(`statsDay`)는 바꾸지 않는다.
- 사용량 창 이름("5시간", "주간")처럼 시간 표기가 아닌 이름은 바꾸지 않는다.

## 할 일

- [x] `useTime()`과 `domain` 메시지(`duration`, `time`)를 위 규칙으로 바꾼다. 초 메시지를 없앤다.
- [x] 1분 안 경과가 더는 초 단위로 바뀌지 않으면, 화면을 매초 다시 그리던 갱신이 있는지 찾아 분 단위로 충분한지 본다. 바꾸면 PR 본문에 적는다.
- [x] `TimeSlot` 최소 폭(`size.timeColumn`)에 `1 hr 59 min`·`<1 min`·`2 days`가 들어가는지 확인하고, 필요하면 폭을 맞춘다.
- [x] ADR 0010 7번(시간 표기)에 갱신을 적고, `packages/ui/DESIGN.md`의 시간 설명과 예("42초째", "25분째")를 맞춘다. GLOSSARY에 시간 표기 낱말이 있으면 맞춘다.
- [x] 시간 문구를 보는 기존 시험을 새 표기로 고친다.

## 완료 조건

- 단위 시험: 0초, 59초, 60초, 59분 59초, 1시간 정각, 1시간 3분, 23시간 59분, 24시간, 47시간, 49시간을 `elapsed`·`duration`·`ago`로 각각 확인한다.
- 화면 어디에도 "초", "째", "N시간 N분" 경과 표기가 남지 않는다(메시지 파일 검색 결과를 PR 본문에 적는다).
- 스크린숏: Dashboard 카드 하나(1시간 넘은 경과)와 Runs 표 시간 열. 가상 데이터.
- DB 변경 없음. two-way.
